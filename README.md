# HK's SRT Burner

Burn subtitles from an SRT file into a video with the included Python application. This uses ffmpeg on top of a Python GUI (tkinter) in order to make the entire process as easy as possible.

## Install
Just run
```bash
cd downloads 
git clone https://github.com/Hiroshi-Kelner/HK-s-SRT-Burner
```
## Setup

1. Install Python and ensure `python` and `winget` are available in `PATH`.
2. Open `setup.bat` and select **Run as administrator**. This will install ffmpeg
3. And you're done! Just run HK's SRT Burner.py

## Requirements

- Windows
- Python 3
- FFmpeg

The application uses Python's built-in Tkinter UI and has no requirements beyond Python itself and FFmpeg.
